## 🚀 О проекте

Этот проект — не просто приложение для хранения цитат. Это интерактивный курс, созданный для того, чтобы показать вам путь от простого, монолитного JavaScript-приложения до профессионально собранного продукта с использованием современных инструментов.

На примере простого и понятного приложения **«Коллекция цитат»** мы пройдем все этапы:
1.  Создание работающего приложения.
2.  Анализ его слабых мест.
3.  Знакомство с экосистемой Node.js и npm.
4.  Внедрение Webpack для управления сборкой проекта.
5.  Разделение кода на модули.

## 📝 Функционал приложения (базовая версия)

Приложение, которое мы создали, уже умеет:

*   ➕ **Добавлять цитаты**: пользователь вводит текст цитаты и имя автора.
*   🗑️ **Удалять цитаты**: каждая цитата имеет кнопку для удаления.
*   💾 **Сохранять данные**: все цитаты автоматически сохраняются в `localStorage` браузера и не исчезают после обновления страницы.
*   🎨 **Отображать стили**: приятный и современный дизайн с градиентным фоном и аккуратными карточками.

## ⚠️ Проблемы, которые мы выявили

Наше простое приложение столкнулось с типичными проблемами разработки:

1.  **Атомизм зависимостей**: Подключение внешних библиотек требует ручного скачивания и подключения файлов, что неудобно и подвержено ошибкам.
2.  **"Ад зависимостей"**: Желание разбить код на множество логических файлов (`storage.js`, `ui.js`) приводит к необходимости вручную подключать каждый из них в HTML, отслеживая порядок подключения.
3.  **Современный JavaScript**: Мы не можем в полной мере использовать возможности современного JavaScript (например, `import/export`), так как старые браузеры их не поймут.
4.  **Отсутствие оптимизации**: CSS и JS загружаются "как есть", без сжатия (минификации), что замедляет загрузку страницы.
5.  **Смешение окружений**: Настройки (например, URL API) прописываются прямо в коде, что делает невозможным использование разных конфигураций для разработки и продакшена.

## 🛠️ Решение: Знакомство с Node.js и Webpack

Для решения этих проблем мы начинаем использовать мощные инструменты:

### Node.js и npm
*   **Node.js** — это среда выполнения JavaScript вне браузера. Она позволяет нам запускать инструменты разработки на нашем компьютере.
*   **npm (Node Package Manager)** — это менеджер пакетов, который помогает устанавливать и управлять библиотеками и инструментами, используемыми в проекте.

### Webpack
**Webpack** — это статический модульный сборщик. Он берет все наши файлы (JavaScript, CSS, изображения), анализирует их зависимости и собирает в один или несколько оптимизированных файлов (бандлов), которые мы отдаем браузеру.

## ⚙️ Установка и настройка

### Предварительные требования
Убедитесь, что на вашем компьютере установлен Node.js и npm. Проверить можно в терминале:

```bash
node --version
npm --version
```

### Шаги для воспроизведения

1.  **Создайте `root` папку проекта и перейдите в папку проекта:**
    ```bash
    cd quotes-app
    ```

2.  **Инициализируйте проект:**
    ```bash
    npm init -y
    ```
    Эта команда создаст файл `package.json` — "паспорт" проекта.

3.  **Установите Webpack:**
    ```bash
    npm install --save-dev webpack webpack-cli
    ```
    Эта команда добавит Webpack в раздел `devDependencies` и создаст папку `node_modules` для хранения всех установленных пакетов.

4.  **Создайте конфигурационный файл `webpack.config.js`:**
    ```javascript
    const path = require('path');

    module.exports = {
        entry: './script.js',        // Точка входа
        output: {
            path: path.resolve(__dirname, 'dist'),
            filename: 'bundle.js'    // Итоговый файл
        },
        mode: 'development'          // Режим сборки
    };
    ```

5.  **Добавьте скрипт сборки в `package.json`:**
    ```json
    "scripts": {
      "build": "webpack"
    }
    ```

6.  **Запустите сборку:**
    ```bash
    npm run build
    ```
    После этого в проекте появится папка `dist` с файлом `bundle.js`.

7.  **Обновите HTML:**
    Замените подключение старого скрипта на новый.
    ```html
    <!-- Было -->
    <script src="script.js"></script>

    <!-- Стало -->
    <script src="dist/bundle.js"></script>
    ```

## 🎬 Проверка и эксперименты

1.  **Запустите** `index.html` в браузере. Приложение должно работать как и раньше.
2.  **Поэкспериментируйте** с конфигурацией Webpack. В файле `webpack.config.js` измените `mode: 'development'` на `mode: 'production'` и выполните сборку заново (`npm run build`).
3.  **Сравните** файлы `dist/bundle.js` до и после. В `production`-режиме код будет минифицирован и нечитаем для человека, но значительно меньше по размеру.

## 🐛 Возможные проблемы и их решение

*   **Ошибка при запуске `npm run build`**:
    *   Убедитесь, что вы находитесь в правильной директории (где есть `webpack.config.js`).
    *   Проверьте, установлен ли Webpack: `npm list webpack`.
    *   Попробуйте удалить `node_modules` и переустановить зависимости: `rm -rf node_modules && npm install` (на Windows используйте `rd /s /q node_modules`).
