## 2. Теория: Canvas и глобальные функции (15 минут)

### Часть 1. Глобальные функции через window

В этом проекте мы используем простой подход: все функции будут доступны через объект `window`. Это значит, что мы пишем:

```javascript
// В js/core.js
window.drawPlayer = function(ctx, x, y) {
    // код функции
};
```

И потом можем вызвать из любого места просто:
```javascript
drawPlayer(ctx, 400, 300);
```

**Почему так?** Это самый простой способ для новичков — не нужно думать про импорты и экспорты, функции автоматически доступны везде.

### Часть 2. Canvas API

Canvas — это элемент HTML5, на котором мы можем рисовать с помощью JavaScript.

**Получение контекста:**
```javascript
const canvas = document.getElementById('gameCanvas');
const ctx = canvas.getContext('2d'); // ctx = context (контекст)
```

**Система координат:**
- Начало координат (0, 0) — **левый верхний угол**
- Ось X растёт вправо
- Ось Y растёт вниз

**Основные команды рисования:**

1. **Круг**
   ```javascript
   ctx.beginPath();
   ctx.arc(200, 200, 30, 0, Math.PI * 2); // x, y, радиус, начало, конец
   ctx.fillStyle = 'blue';
   ctx.fill();
   ```

2. **Прямоугольник**
   ```javascript
   ctx.fillStyle = 'brown';
   ctx.fillRect(195, 280, 10, 40); // x, y, ширина, высота
   ```

3. **Линия**
   ```javascript
   ctx.beginPath();
   ctx.moveTo(100, 100); // Начало линии
   ctx.lineTo(200, 200); // Конец линии
   ctx.strokeStyle = 'yellow';
   ctx.lineWidth = 2;
   ctx.stroke();
   ```

4. **Текст**
   ```javascript
   ctx.font = '14px Arial';
   ctx.fillStyle = 'black';
   ctx.fillText('HP: 100', 220, 25); // текст, x, y
   ```

5. **Очистка canvas**
   ```javascript
   ctx.clearRect(0, 0, canvas.width, canvas.height);
   ```
   **Важно:** Без очистки старые рисунки остаются, и получается "смазывание".

## 3. Практика: рисуем игру (60 минут)

### Общая структура

В `index.html` уже есть элемент canvas и подключены все скрипты:
```html
<canvas id="gameCanvas" width="800" height="600" style="border:1px solid black;"></canvas>

<script src="js/core.js"></script>
<script src="js/ui.js"></script>
<script src="js/ai.js"></script>
<script src="js/graphics.js"></script>
<script src="js/effects.js"></script>
<script src="js/main.js"></script>
```

В `main.js` уже есть игровой цикл, который вызывает все функции:
```javascript
const canvas = document.getElementById('gameCanvas');
const ctx = canvas.getContext('2d');

function gameLoop() {
    ctx.clearRect(0, 0, canvas.width, canvas.height);
    
    // Здесь вызываются функции отрисовки
    drawTree(ctx, 200, 300);
    drawTree(ctx, 500, 400);
    drawEnemy(ctx, 300, 200, 'spider');
    drawEnemy(ctx, 600, 350, 'hound');
    drawPlayer(ctx, 400, 300);
    drawPickupEffect(ctx, 450, 250);
    drawHungerHealth(ctx, 75, 60);
    
    requestAnimationFrame(gameLoop);
}

gameLoop();
```

## Важные моменты и частые ошибки

### Ошибка 1: Забыли window.
```javascript
// Неправильно
function drawPlayer(ctx, x, y) { } // функция не будет доступна глобально

// Правильно
window.drawPlayer = function(ctx, x, y) { }
```

### Ошибка 2: Не очистили canvas
Без `ctx.clearRect()` старые кадры будут видны, и получится "след".

### Ошибка 3: Забыли beginPath()
```javascript
// Неправильно
ctx.arc(100, 100, 15, 0, Math.PI*2); // может нарисоваться поверх старого

// Правильно
ctx.beginPath();
ctx.arc(100, 100, 15, 0, Math.PI*2);
```

### Ошибка 4: Конфликты при merge
Если при создании PR GitHub говорит о конфликтах:
```bash
git checkout develop
git pull origin develop
git checkout feature/lesson2-своя-ветка
git merge develop
# Решаем конфликты вручную в файлах
git add .
git commit -m "Resolve merge conflicts"
git push origin feature/lesson2-своя-ветка
```
