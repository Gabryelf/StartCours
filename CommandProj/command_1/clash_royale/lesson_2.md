### 2. Теория: Canvas и Git Workflow (15 минут)

#### Canvas (8 минут)

Показываю на экране с живыми примерами:

```javascript
// Получаем холст и контекст
const canvas = document.getElementById('gameCanvas');
const ctx = canvas.getContext('2d');

// КООРДИНАТЫ: (0,0) — левый верхний угол
// X растёт вправо, Y растёт вниз

// 1. Прямоугольник (залитый)
ctx.fillStyle = 'brown';
ctx.fillRect(50, 50, 100, 80);  // x, y, ширина, высота

// 2. Прямоугольник (только контур)
ctx.strokeStyle = 'black';
ctx.lineWidth = 2;
ctx.strokeRect(50, 50, 100, 80);

// 3. Круг
ctx.fillStyle = 'yellow';
ctx.beginPath();                 // ВАЖНО: начинаем новый путь!
ctx.arc(200, 100, 30, 0, Math.PI * 2);  // x, y, радиус, начало, конец
ctx.fill();

// 4. Линия
ctx.strokeStyle = 'yellow';
ctx.lineWidth = 2;
ctx.beginPath();
ctx.moveTo(300, 100);            // начало линии
ctx.lineTo(350, 150);            // конец линии
ctx.stroke();

// 5. Текст
ctx.fillStyle = 'black';
ctx.font = '16px Arial';
ctx.fillText('Привет, игра!', 400, 100);

// 6. Очистка canvas (ОЧЕНЬ ВАЖНО!)
ctx.clearRect(0, 0, canvas.width, canvas.height);
```

**Демонстрирую важные моменты:**
- Без `beginPath()` линии будут рисоваться поверх старых
- Без `clearRect()` каждый кадр будет рисоваться поверх предыдущего
- Цвета можно задавать именами ('red'), HEX ('#ff0000') или RGB ('rgb(255,0,0)')

## 🚨 Частые проблемы и их решения

### Проблема 1: Функция не видна в main.js
```javascript
// Неправильно
function drawPlayer(ctx, x, y) { }  // функция не глобальная

// Правильно
window.drawPlayer = function(ctx, x, y) { }  // прикрепляем к window
```

### Проблема 2: Всё рисуется, но потом исчезает
**Причина:** `ctx.clearRect()` в gameLoop стирает всё каждый кадр.
**Решение:** Убедиться, что все функции отрисовки вызываются **после** очистки, но **до** `requestAnimationFrame`.

### Проблема 3: Линии рисуются поверх старых
**Причина:** Забыли `ctx.beginPath()` перед новой линией.
**Решение:**
```javascript
ctx.beginPath();  // ВСЕГДА перед новой линией или кругом
ctx.moveTo(x, y);
ctx.lineTo(x2, y2);
ctx.stroke();
```

### Проблема 4: Конфликт при merge
**Ситуация:** GitHub пишет "Can't automatically merge"
**Решение:**
```bash
git checkout develop
git pull origin develop
git checkout feature/своя-ветка
git merge develop
# VS Code покажет конфликты, решаем их
git add .
git commit -m "merge: resolve conflicts"
git push
```

### Проблема 5: git push просит пароль каждый раз
**Решение:** Настроить SSH-ключ или использовать:
```bash
git config --global credential.helper store
```
