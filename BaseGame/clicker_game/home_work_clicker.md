## 📚 Инструкция по коду

### Структура HTML (контейнеры):
```
<div class="container">          ← Главный контейнер всей игры
├── <header>                    ← Шапка с названием и счетчиками
│   ├── <h1>                   ← Заголовок игры
│   └── <div class="score-container"> ← Контейнер для очков
│       ├── <div class="score">      ← Текущие очки
│       └── <div class="next-level"> ← До следующей картинки
├── <main>                     ← Основное содержание
│   ├── <div class="main-image-container"> ← Контейнер главной картинки
│   │   ├── <img id="main-image">   ← Сама картинка (меняется)
│   │   └── <div class="image-info"> ← Название картинки
│   ├── <div class="click-area">    ← Область для кликов
│   │   ├── <button id="click-button"> ← Кнопка для кликов
│   │   └── <div class="click-info">   ← Информация о кликах
│   └── <div class="progress-container"> ← Прогресс бар
│       ├── <div class="progress-bar">   ← Полоска прогресса
│       │   └── <div id="progress-fill"> ← Заполненная часть
│       └── <div class="progress-text">  ← Текст процентов
└── <footer>                    ← Подвал (пока пустой)
```

### Основные функции в JavaScript:

1. **`updateScore()`** - Обновляет счетчик очков на экране
   - Берет значение из переменной `score`
   - Вставляет его в элемент с id="score"

2. **`updateProgress()`** - Обновляет прогресс бар
   - Вычисляет процент до следующей картинки
   - Меняет ширину синей полоски
   - Обновляет текст с процентами

3. **`updateNextLevelInfo()`** - Показывает, сколько очков нужно для следующей картинки
   - Если есть следующая картинка - показывает порог
   - Если все открыто - пишет "МАКСИМУМ!"

4. **`checkForImageChange()`** - Проверяет, нужно ли менять картинку
   - Сравнивает текущие очки с порогом для следующей картинки
   - Если очков достаточно - вызывает `changeImage()`

5. **`changeImage(index)`** - Меняет главную картинку
   - Берет новую картинку из массива `GAME_SETTINGS.images`
   - Берет новое название из массива `GAME_SETTINGS.imageNames`
   - Обновляет картинку и название на странице

6. **`handleClick()`** - Обрабатывает клик по кнопке
   - Увеличивает счет на 1
   - Обновляет все отображения
   - Проверяет смену картинки
   - Создает эффект "+1"

7. **`initGame()`** - Запускает игру при загрузке страницы
   - Настраивает начальные значения
   - Добавляет обработчики событий
   - Добавляет CSS для анимаций

### Важные алгоритмы для понимания:

1. **Как работает смена картинок:**
   - Есть массив порогов: `[10, 25, 50, 100, 200, 500]`
   - Когда очки достигают 10 → меняется на 2-ю картинку
   - Когда очки достигают 25 → меняется на 3-ю картинку
   - И так далее...

2. **Как считается прогресс:**
   ```
   Процент = (Текущие очки - Предыдущий порог) / (Следующий порог - Предыдущий порог) * 100
   
   Пример: у нас 40 очков, предыдущая картинка была при 25, следующая при 50
   Процент = (40 - 25) / (50 - 25) * 100 = 15 / 25 * 100 = 60%
   ```

3. **Как работают события:**
   - `clickButton.addEventListener('click', handleClick)` - при клике на кнопку
   - `document.addEventListener('keydown', ...)` - при нажатии клавиши (пробел)
   - `window.addEventListener('load', initGame)` - когда страница загрузится

### Настройки игры (GAME_SETTINGS):
```javascript
const GAME_SETTINGS = {
    imageThresholds: [10, 25, 50, 100, 200, 500], // Пороги смены картинок
    images: ["./images/1.png", "./images/2.png", ...], // Пути к картинкам
    imageNames: ["Nidoking", "Nidoqueen", ...] // Названия картинок
};
```
