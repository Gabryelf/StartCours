ТЕХНИЧЕСКОЕ ЗАДАНИЕ: Pokemon Clicker
Описание проекта
Игра-кликер, где игрок кликает по кнопке, зарабатывает очки и открывает новые изображения покемонов при достижении определенных порогов очков.

Текущие проблемы игры
Игра была повреждена в результате "несчастного случая" в репозитории. Вам необходимо восстановить ее работоспособность.

ЗАДАНИЕ:

___

**Задача 1: Восстановить index.html**

Проблемы:

Страница загружается, но отображается неправильно

Элементы расположены хаотично

Не работают иконки

Текст отображается некорректно

Кнопка клика не стилизована должным образом

Отсутствует важная информация в подвале

___

**Что должно быть:**

Чистый, структурированный HTML

Все элементы на своих местах

Рабочие иконки FontAwesome

Корректное отображение текста на русском

Красивая кнопка для кликов

Информационная секция в подвале

____

**Задача 2: Восстановить style.css**

Проблемы:

Страница не адаптивная

Цветовая схема нарушена

Элементы перекрывают друг друга

Прогресс-бар не виден

Картинка покемона слишком большая/маленькая

На мобильных устройствах игра ломается

Вертикальный скролл появляется на некоторых экранах

___

Что должно быть:

Адаптивный дизайн

Приятная цветовая схема (темная тема)

Все элементы видны и не перекрываются

Рабочий прогресс-бар с анимацией

Картинка покемона оптимального размера

Мобильная версия игры

Все элементы видны без вертикального скролла на экранах от 768px

___

**Задача 3: Восстановить script.js**

Проблемы:

Кнопка клика не увеличивает счет

Картинки не меняются при достижении порогов

Прогресс-бар не заполняется

Не работает подсчет до следующей картинки

Нет анимации при клике

Не работают "читы" для тестирования

Клавиша пробела не работает для кликов

В консоли появляются ошибки

___

Что должно быть:

Клик по кнопке увеличивает счет на 1

При достижении порога очков меняется картинка

Прогресс-бар показывает прогресс до следующей картинки

Отображается сколько очков осталось до следующей картинки

Визуальный эффект при клике (+1 всплывает)

Возможность использовать читы в консоли для тестирования

Клик по пробелу работает как клик по кнопке

Чистая консоль без ошибок

___


КРИТЕРИИ ПРОВЕРКИ
Обязательные требования:
Игра запускается без ошибок

Клик по кнопке увеличивает счет

Картинка меняется при достижении 10, 25, 50, 100, 200 очков

Прогресс-бар заполняется плавно

На экране 768px высотой нет вертикального скролла

Все элементы видны без прокрутки

Адаптивный дизайн для мобильных устройств

___

**ПОДСКАЗКИ:**

Для отладки используйте:

Консоль разработчика (F12)

Console.log() для отслеживания значений

Проверку элементов на странице

Проверяйте:

Существуют ли файлы по указанным путям

Правильно ли подключены скрипты и стили

Нет ли синтаксических ошибок в JavaScript

Последовательность восстановления:

Сначала сделайте так, чтобы страница отображалась

Затем добавьте функциональность клика

Потом восстановите смену картинок

Наконец, настройте адаптивность

Для решения проблемы со скроллом:

Проверяйте общую высоту всех элементов

Используйте max-height и overflow

Тестируйте на разных размерах экрана
