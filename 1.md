🛡️ Проект: Arena Survivors — Учебная разработка игры на JavaScript
Внутренняя документация проекта
Для учеников и наставников. Цель: создать модульную, расширяемую игру в браузере, используя принципы ООП и командную разработку.

🎮 Концепция и видение
Мы создаем игру в жанре выживание на арене с элементами RPG и крафта. Игрок выбирает героя, сражается на локациях, получает награды и улучшает персонажей.

Ключевые особенности:

🧩 Модульность — каждый модуль можно заменить или отключить.
📱 Адаптивность — игра корректно отображается на любом экране (никакого скролла страницы, только внутренние скроллы).
💾 Локальные сохранения — прогресс хранится в localStorage.
⚙️ Итерационная разработка — каждый новый кусочек кода работает сразу.
📁 Структура проекта
Проект организован по принципу разделения ответственности (Separation of Concerns). У нас есть чёткое разделение на:

Ядро (Core) — игровая логика, сущности, математика.
Пользовательский интерфейс (UI) — отрисовка, обработка кликов.
Состояние (State) — единый источник правды (Single Source of Truth).

Правило:

Модули из core/ не знают о существовании UI.
Модули из ui/ только читают состояние и подписываются на изменения.
game.js — дирижёр, который всё собирает.

🦁 Hero.js
Главный класс игры. Отвечает за:

Хранение базовых характеристик (HP, атака, защита, скорость).
Уровень и опыт (формулы прироста статов).
Инвентарь героя (массив из 9 слотов).
Методы экипировки/снятия предметов.

🗡️ Item.js
Базовый класс для всего, что можно положить в инвентарь.

class Item {
    constructor(id, name, type, rarity, statsBonus = {}) {
        this.id = id;
        this.name = name;
        this.type = type; // 'weapon', 'armor', 'consumable'
        this.rarity = rarity; // 'common', 'rare', 'epic'
        this.statsBonus = statsBonus; // { hp: +10, attack: +5 }
        this.skillModifier = null; // Если предмет модифицирует навык
    }
}
Типы предметов:

weapon_melee — ближний бой.
weapon_ranged — дальний бой (требует перезарядки).
armor — броня (шлем, нагрудник и т.д.).
consumable — расходник (зелье, бомба).
